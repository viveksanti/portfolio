# Vivek Santi Portfolio

A fast, editable static portfolio with no build step or paid services required.

## Edit content

Open `content.js` and change the intro, projects, experience, or skills. Contact links and page metadata live in `index.html`. Visual styling lives in `styles.css`. The résumé download is currently hidden; add its link back to `index.html` when the revised PDF is ready.

Open `index.html` directly in a browser to preview the site.

## Host free with GitHub Pages

1. Create a public GitHub repository and upload these files.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.

GitHub will provide a shareable URL. Netlify and Cloudflare Pages also support this project with no build command; use the repository root as the publish directory.
